# Revenue Signals™ — Kartik Clarity™

A GitHub Pages-ready, client-side executive revenue diagnostic.

## Run locally
Open `index.html` directly, or serve the repository with any static web server.

## Deploy
This repository is intentionally static so GitHub Pages can serve it directly from the `main` branch root.

GitHub Pages settings:
- Source: Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

No server, database, API key, or build step is required.

## Brand assets
The site uses the two supplied Kartik Clarity™ assets:
- `assets/logo-circle.jpeg`
- `assets/logo-rectangle.jpeg`

The interface uses the logo-derived Kartik Clarity™ navy/blue/cyan/white visual system.

## Diagnostic
Revenue Signals™ evaluates supplied business evidence in-browser and distinguishes:
- strong signals
- warning signals
- contradictory signals
- evidence blind spots
- potential revenue exposure
- next investigation actions

The Tool Finder is built into the page.
